
### Étape 1 : Déposer vos fichiers
* **Glisser-Déposer** : Déposez directement vos fichiers ou dossiers dans le réceptacle gauche.
* **Bouton Parcourir** : Cliquez sur `📁 Parcourir les Fichiers...` pour sélectionner vos vidéos, musiques, images, documents, modèles 3D ou pages HTML.

* 🎵 **Audio** : MP3 320 kbps, FLAC lossless 24-bit, WAV studio, AAC, Opus voix.

* 🌐 **Web/Anim** : Capture déterministe de HTML5, Canvas 2D, WebGL, Three.js et Lottie JSON vers MP4 60 fps.
* 🧊 **Modèles 3D** : OBJ, STL, PLY vers Vidéo 360° MP4 avec rotation studio ou conversion géométrique.
